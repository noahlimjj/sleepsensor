Install with SideStore free · no account fee

The zero-cost way. SideStore keeps the app fresh automatically using your own free Apple ID — no computer needed after the one-time setup.

Download the .ipa
  1. Install SideStore: follow sidestore.io (one-time, ~15 min).
  2. Download the .ipa above.
  3. In SideStore → + → pick the file → sign in with your Apple ID.
  4. SideStore re-signs it every 7 days in the background. Done.

AltStore works too if you prefer the desktop app.

Full guide: docs/SIDELOAD.md
